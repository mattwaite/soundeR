# soundeR

A beginner-friendly, tidyverse-style R package for data sonification
(e.g. `games |> sonify_data(point_margin, instrument = "xylophone", bpm = 120)`).

**Read `PLAN.md` first.** It holds the design, target API, architecture,
open decisions, roadmap, and a session log. At the end of each work
session, append to the session log in `PLAN.md` and update any decisions
that changed.

Audience: students in an intro data analysis class. Favor friendly
defaults, `cli` error messages, and zero system dependencies on the
default path.
